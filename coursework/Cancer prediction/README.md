### Is it possible to train a Machine Learning model to diagnose cancer from images and metadata?
- Used Cancer prediction dataset from Kaggle
- Trained supervised machine learning models like Random Forest, Support Vector Machine, Logistic Regression, etc.
- Created two ensemble models with Weighted Average and Blending (data split) & implemented them using Random Forest and Gradient Boosting algorithms.

**Results:** The ensemble models performed better than the individual models and achieved high accuracy ~94%.
